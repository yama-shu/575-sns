## 背景・目的

[S-03 投稿詳細](../design/basic/04-screens.md#1-画面一覧) と
[S-04 ユーザーページ](../design/basic/04-screens.md#1-画面一覧)（[FR-03-05](../requirements/01-requirements.md#fr-03-閲覧)）を作るための API を実装する。

**画面を作る前に api が足りない。**
[基本設計 05 §ユーザー](../design/basic/05-api.md) は次の2つを定めているが、どちらも未実装である。

| メソッド | パス | 状態 |
| --- | --- | --- |
| GET | `/api/v1/users/:handle` | **未実装** |
| GET | `/api/v1/users/:handle/posts` | **未実装** |

S-03 に必要な `GET /posts/:id` は [#30](https://github.com/yama-shu/575-sns/issues/30) で実装済みである。
足りないのは S-04 の側だけだが、**画面からフォローする導線もここに載る**。

いま画面からは誰もフォローできない。フォロー中タイムライン（S-02）という画面がありながら、
フォローするには `curl` を叩くしかない状態になっている。

## 実装上の注意

### 見えない相手は存在しないものとして扱う

[BR-10](../design/basic/02-domain-model.md) のとおり、**ブロックされた側にそれを知らせない**。
403 や 422 を返すと「ブロックされている」と分かってしまう。

[#34](https://github.com/yama-shu/575-sns/issues/34) の `resolveTarget` が同じ判断をしている。同じ扱いに揃える。

| 状況 | 応答 |
| --- | --- |
| 閲覧者が相手をブロックしている | 404 |
| 相手が閲覧者をブロックしている | 404 |
| 相手が利用停止 | 404 |
| 相手が退会済み | 404 |
| 識別名が存在しない | 404 |

**理由を区別しない。** 区別すると存在を教えてしまう。

利用停止を 404 にするのは、[基本設計 02 §3](../design/basic/02-domain-model.md#3-利用者の状態遷移) が
「投稿は非表示になる」としているためである。プロフィールだけ見えて投稿が空になるより、
一貫して見えない方がよい。

> 利用停止を行う API はまだ無い（`/api/v1/admin/*` は未実装）。
> **行を直接入れて確かめる。** 実装できないから確かめない、にしない。

### フォロワー限定の投稿を誰に見せるか

[FR-02-08](../requirements/01-requirements.md#fr-02-投稿詠む) の公開範囲を、一覧でも効かせる。

| 閲覧者 | 見える投稿 |
| --- | --- |
| 本人 | 全体公開 + フォロワー限定 |
| フォロワー | 全体公開 + フォロワー限定 |
| それ以外・未ログイン | 全体公開のみ |

[#30](https://github.com/yama-shu/575-sns/issues/30) の `Post.IsVisibleTo` と同じ規則である。
**規則を2箇所に書かない。** 既存の判断を使う。

### 投稿数は閲覧者から見える数にする

フォロワー限定を含めた総数を返すと、**一覧に出ている件数と合わない**。
「10句」と出ているのに3件しか見えないのは、数え方の説明がつかない。

閲覧者から見える投稿の数を返す。閲覧者によって変わることを OpenAPI に書く。

### 数え方に索引が効くか確かめる

- 投稿一覧: `posts_author_timeline_idx (author_id, id DESC) WHERE status='published'`
- フォロー数: `follows_pkey (follower_id, followee_id)`
- フォロワー数: `follows_followee_id_idx (followee_id)`

**いずれも既にある。** 移行は不要である。実行計画を見て、
`Seq Scan` になっていないことを確かめる。

### 3つの数を1回で取る

投稿数・フォロー数・フォロワー数を別々に問い合わせると、
プロフィール1枚で4回のクエリになる。1つの文にまとめる。
