## 背景・目的

本文からモーラ数を数えるには、まず読みを確定しなければならない。
その読みを SudachiPy から取得する。

[ADR-0003](../adr/0003-morphological-analyzer.md#解析器を差し替え可能にする) では、
**解析器を差し替え可能にする**と決めている。
SudachiPy の選定は速度・精度の実測前に行った判断を含むため、
乗り換えが必要になる可能性がある。

また形態素解析は読みを必ず返すとは限らない。
数字・ラテン文字・未知語への対処が要る。

## 実装上の注意

### `unknown` を `hacho` にしない

読みが取れなかっただけで「五七五になっていません」と返してはならない。
ユーザーは正しく詠んでいるかもしれず、そう言われても直しようがない。

```
❌ 「五七五になっていません」
✅ 「『甃』の読み方が分かりませんでした」
```

TC-RR-08 がこれを検証する。

### 依存の向きを守る

`SudachiTokenizer` 以外のクラスが SudachiPy に依存していないことを、
**テストではなく静的解析で担保する**（import 制約のチェック）。
テストだけだと、後から誰かが直接 import しても気づけない。
