## 背景・目的

[#52](https://github.com/yama-shu/575-sns/issues/52) の実装後、**ヘッドレス Chrome で画面を撮って**見つかった不具合を直す。

これまでの検証は `curl` と DOM の値で行っており、**見た目そのものを見ていなかった**。
値が正しくても表示が壊れていることは検出できていなかった。

## 何が壊れているか

### 1. 句と句の間が空きすぎる

`<p>` の既定マージン（18.4px）が残っている。

```
$ getComputedStyle(document.querySelector('article p[class*="segment"]'))
{ marginTop: "18.4px", marginBottom: "18.4px", lineHeight: "36.8px" }
```

[PostCard.module.css](../../web/src/components/PostCard.module.css) の `.body` は
`display: grid; gap: 2px` で間隔を決めているつもりだったが、
そこに既定マージンが上乗せされ、句の間が約 37px 空いている。

**五七五がひと続きの句ではなく、3つの段落に見える。**
[基本設計 04 §4](../design/basic/04-screens.md#4-投稿の表示形式) は
「形式そのものがプロダクトの価値であるため、それを見せる」としており、
その見せ方が崩れている。

同じ原因で、判定結果のパネルでもバッジと理由の間が空いている。

### 2. 狭い画面でヘッダーが崩れる

390px（iPhone 相当）で、

- 「全体タイムライン」が語の途中で2行に折り返す
- 「ログアウト」がボタンの中で**3行**に折り返す

[NFR-06-01](../requirements/01-requirements.md#nfr-06-ユーザビリティ) は
スマートフォンでの利用を主としている。**主たる環境が一番崩れている。**

### 3. ハイドレーションの不一致

Next.js の開発オーバーレイが警告を出していた。

```
Recoverable Error
Hydration failed because the server rendered text didn't match the client.
  ... <PublicTimelinePage> <AppShell> <Timeline>
```

原因は [RelativeTime](../../web/src/components/RelativeTime.tsx) である。

```
SSR     : title="2026/8/11 6:22:16"    ← コンテナは UTC
ブラウザ : title="2026/8/11 15:22:16"   ← Asia/Tokyo
```

`toLocaleString("ja-JP")` は**実行環境のタイムゾーンに依存する**。
サーバー（コンテナ = UTC）とブラウザ（JST）で違う文字列になる。

**このコンポーネントの但し書きに反している。**

> **サーバー側で計算しない。** 計算した HTML がキャッシュされると古い表示が残り、
> 閲覧者との時差でもずれる。

相対時刻はクライアントで作るようにしたが、**絶対時刻の整形はサーバーでやっていた**。

## 実装上の注意

### 既定マージンは1箇所で断つ

`.segment` だけを直しても、同じ不具合が別の場所で起きる。
現に判定結果のパネルでも起きている。

`globals.css` で `p` の余白を落とし、**必要な余白は各コンポーネントが明示する**。
既存のコンポーネントは `display: grid` と `gap` で間隔を決めているため、
落としても意図した間隔になる。

### タイムゾーンを固定する

**相対時刻をサーバーで計算しないという判断は変えない。** 時間の経過で古くなるためである。

絶対時刻は古くならないため、サーバーで整形してよい。
問題は環境依存であることなので、`timeZone` を明示して**どこで整形しても同じ文字列**にする。

日本語話者向けのサービスであり（[要件定義](../requirements/01-requirements.md)）、
閲覧者の地域に合わせる要件は無い。全員が同じ時刻表記を見る方が、
投稿の前後関係を話題にするときに食い違わない。

### 見た目は撮って確かめる

DOM の値だけでは今回の不具合を検出できなかった。**画面を撮って見る。**
