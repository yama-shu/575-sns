## 実装上の注意

### 「ッ」「ン」「ー」を結合対象に入れない

最も起きやすいバグ。見た目が小さい「ッ」を
拗音（ャュョ）と同じ扱いにしてしまうと、モーラ数が1つ少なくなる。

```python
COMBINING   = set("ァィゥェォャュョヮ")   # 直前と結合する
INDEPENDENT = set("ッンー")               # 単独で1モーラ
```

TC-MC-15〜17（`ッ` 単独 / `ン` 単独 / `ー` 単独 がそれぞれ1モーラ）が
この誤りを直接検出する。**このテストを先に書く。**
