## 背景・目的

[S-01 全体タイムライン](../design/basic/04-screens.md#1-画面一覧)（[FR-03-01](../requirements/01-requirements.md#fr-03-閲覧)）と
[S-02 フォロー中タイムライン](../design/basic/04-screens.md#1-画面一覧)（[FR-03-02](../requirements/01-requirements.md#fr-03-閲覧)）を実装する。

**575 の価値が初めて画面に出る。** [基本設計 04 §4](../design/basic/04-screens.md#4-投稿の表示形式) が
「一行で表示すると、五七五であることが視覚的に分からず、
『なぜこの SNS を使っているのか』が伝わらない」と述べているとおり、
句ごとに改行して見せることがこの画面の役割である。

api は [#38](https://github.com/yama-shu/575-sns/issues/38) と [#41](https://github.com/yama-shu/575-sns/issues/41) で実装済み。
`/` は疎通確認の暫定ページ、`/home` は [#48](https://github.com/yama-shu/575-sns/issues/48) で置いた最小限の画面のままである。

## 実装上の注意

### 再判定しない

[基本設計 04 §4](../design/basic/04-screens.md#4-投稿の表示形式) と
[基本設計 01 §4](../design/basic/01-architecture.md#保存時に判定結果も保存する理由) のとおり、
**改行位置は保存済みの値から復元する。**

api は `segments`（句ごとの本文とモーラ数）を返す。web はこれを並べるだけでよい。
web で本文を分割し直すと、辞書の更新で表示が変わりうるうえ、
prosody が落ちているときに閲覧できなくなる。

### 無限スクロールはボタンを併置する

[FR-03-03](../requirements/01-requirements.md#fr-03-閲覧) は無限スクロールを求めている。
一方 [NFR-06-03](../requirements/01-requirements.md#nfr-06-ユーザビリティ) は
「主要な操作はキーボードのみで完結できる」ことを求めている。

**スクロール検知だけで実装しない。** キーボードだけの利用者と、
JavaScript を無効にしている利用者が過去に遡れなくなる。

「もっと読む」ボタンを置き、スクロールが下端に達したときは
そのボタンを自動で押す形にする。ボタンは常に存在し、
リンクとしても機能させる（JavaScript 無しでも `?cursor=` で次のページへ行ける）。

### カーソルは api の `next_cursor` をそのまま使う

自分で組み立てない。[基本設計 03 §5](../design/basic/03-database.md#5-カーソルページネーション) の
「同一ミリ秒の採番順で1件が読み飛ばされうる」問題を含め、
カーソルの意味は api が持つ。web は受け取った値を返すだけにする。

### ナビゲーションは後から増やせる形にする

[基本設計 04 §6](../design/basic/04-screens.md#6-スコープ外の画面) が
「グローバルナビゲーションの構造は、これらを後から追加できる形にしておく」
としている（通知・検索・お題は第2版）。

項目を配列で持ち、追加が1行で済む形にする。

### 相対時刻はサーバーとクライアントで食い違う

サーバー側で「2時間前」を計算すると、その HTML がキャッシュされた場合や
クライアントとの時差で表示がずれる。

`<time dateTime={...}>` に絶対時刻を持たせ、表示はクライアント側で算出する。
**絶対時刻を属性に残す**ことで、読み上げと機械可読性も保てる。

### 0件のときに何を出すか

「投稿がありません」だけにしない。[NFR-06-02](../requirements/01-requirements.md#nfr-06-ユーザビリティ) の
考え方（理由と次の行動が分かる）を、エラー以外にも適用する。

| 画面 | 状況 | 出す内容 |
| --- | --- | --- |
| S-01 | 誰も投稿していない | 最初の一句を詠むよう促す |
| S-02 | 誰もフォローしていない | 全体タイムラインへ誘導する |
| S-02 | フォロー先が投稿していない | その旨を伝える |
