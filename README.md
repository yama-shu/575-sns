# 575 — 五七五でしか投稿できないSNS

> 言いたいことは、五七五で。

**575** は、投稿本文が五七五（音数律）に収まっていないと投稿できない SNS です。
俳句SNSではありません。季語も切れ字も不要で、投稿する内容は何でも構いません。
制約は「形式」だけです。多少の字余り・字足らずは許容します。

```
     入力: 「今日もまた 会議のための 会議かな」
     判定: ✅ 定型（5 / 7 / 5）→ 投稿可能

     入力: 「今日は疲れた」
     判定: ❌ 破調（7モーラ）→ 投稿不可
```
